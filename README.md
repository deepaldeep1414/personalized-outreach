# 🚀 Outreach Pipeline

An AI-powered outreach management platform that helps users create, track, and review personalized outreach campaigns. The application streamlines prospect management by organizing outreach runs, tracking their status, and providing a centralized dashboard for monitoring campaign progress.

## 📖 Overview

Outreach Pipeline is a web application that simplifies prospect outreach by allowing users to create, manage, and review outreach campaigns from a single dashboard.

Whether you're reaching out to potential clients, recruiters, or business partners, the platform keeps every outreach run organized and easy to track.

## 🚀 Getting Started

### Prerequisites

- Go 1.21 or later

---

### Clone the Repository

```bash
git clone https://github.com/deepaldeep1414/<repository-name>.git
```

```bash
cd <repository-name>
```

---

### Install Dependencies

```bash
go mod tidy
```

---

### Run the Application

```bash
go run .
```

Open your browser at:

```
http://localhost:8080
```

## 📋 How It Works

1. Launch the application.
2. Create a new outreach run.
3. Add prospect and company details.
4. Review generated outreach information.
5. Track the progress from the dashboard.
6. Manage multiple outreach campaigns in one place.
